Notes & About

Neko's Index is a curated resource directory for open-source apps, media tools, privacy utilities, and useful services. It is inspired by community indexes such as theindex.moe, everythingmoe, and fmhy.

What You'll Find Here

  • Open-source streaming, media, and reading apps
  • VPN, DNS, and privacy tools
  • Android, PC, and iOS app lists
  • Video players, converters, and download utilities
  • AI, development, gaming, and utility tools
  • An 18+ resources page (linked in the nav, gated behind an age check)
  • An interface available in 8 languages

How to Use the Site

  • Click the Guide button for a quick overview of features and shortcuts.
  • Click any category header to expand or collapse it.
  • Use the search bar to filter apps by name or tag.
  • Use filter buttons to quickly show Android, PC, iOS, AI, gaming, privacy, tools, downloads, modding, retro, or communities.
  • Click the star on any item to add it to your Favorites.
  • Toggle light/dark mode and open Settings for more options, including Language.
  • Use the 🌐 language switcher (top-right on every page) or the Language dropdown in Settings to change the interface language.
