# Neko's Index

> A curated directory of open-source apps, privacy tools, streaming utilities, and more.

**Live site:** https://neko-s-index.github.io/Nekos-Index/

## About

Neko's Index is a static resource directory inspired by community indexes like EverythingMoe and theindex.moe. It collects links to open-source apps, media tools, privacy software, VPN/DNS services, and other useful resources in one place.

## Pages

- **index.html** — Privacy verification landing page
- **list.html** — Main resource directory with search, filters, and categories
- **guides.html** — Setup guides for PC, Android, VPN/DNS, and streaming tools
- **disclaimer.html** — Disclaimer and safety information
- **dmca.html** — DMCA policy
- **privacy.html** — Privacy policy
- **notes.html** — About, usage notes, and changelog
- **404.html** — Custom not-found page

## Features

- Search resources by name and tags
- Category filters for Android, PC, iOS, AI, Gaming, Privacy, Tools, Downloads, and more
- Favorites saved in local storage
- Light and dark theme toggle
- Collapsible categories with a responsive, scrollable layout
- Settings panel with import/export, compact mode, auto-collapse, and warning toggles
- GitHub star badges for repository links
- Cross-site menu bar and footer navigation
- Mobile and desktop responsive design

## Safety

Neko's Index does not host any files or content. All links point to third-party websites and open-source projects. Always download from official sources, scan unknown files with [VirusTotal](https://www.virustotal.com), and keep your antivirus or anti-malware software up to date. We recommend tools like [Malwarebytes](https://www.malwarebytes.com) and [Avast](https://www.avast.com) as part of a safe setup.
