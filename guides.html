Safety & Verification

This index links to third-party websites and open-source projects. Always be cautious when downloading software from the internet, especially executable files and APKs.

  • Download apps from their official website or a trusted store such as F-Droid, Flathub, or the developer's GitHub releases page.
  • Before running a downloaded file, scan it with VirusTotal. It checks the file with many antivirus engines at once.
  • Keep an antivirus or anti-malware tool installed and updated, such as Malwarebytes or Avast.
  • Read user reviews, GitHub issues, and community feedback before installing lesser-known apps.
  • Keep your operating system, browser, and apps up to date to avoid known security holes.
  • Use a VPN or private DNS if you want extra privacy, but remember that no tool is 100% anonymous.

PC Apps — Getting Started

  • Package managers (Windows): Use Scoop, Chocolatey, or winget to install open-source apps from the command line.
  • Video players: Download mpv or VLC. Drag and drop a file or URL to play.
  • Torrenting: Use qBittorrent or Transmission. Always make sure your downloads are legal in your region.
  • Archives / utilities: 7-Zip and PeaZip handle zip, rar, 7z, and more.
  • Privacy / ad blocking: Try Brave, LibreWolf, uBlock Origin, or Privacy Badger.

Android Apps — Getting Started

  • Alternative app store: Install F-Droid or Droid-ify for open-source apps outside Google Play.
  • Play Store without Google: Aurora Store lets you download APKs anonymously.
  • Unknown sources: On Android, go to Settings > Security (or Apps) and allow installs from your file manager or browser for APK files.
  • YouTube apps: NewPipe and LibreTube are ad-free alternatives.
  • Video / anime / manga readers: Apps like Aniyomi, Mihon, and Aidoku use extensions; install the app first, then add extensions from within it.

VPN & DNS — Quick Setup

  • VPN clients: Download the official client for WireGuard or OpenVPN. Import a config file from your provider.
  • Private DNS (Android): Settings > Network & Internet > Private DNS > enter a hostname such as dns.adguard-dns.com or your NextDNS address.
  • DNS on PC / router: Use AdGuard DNS, NextDNS, Quad9, or run your own Pi-hole.
  • Mesh / self-hosted VPNs: Tailscale, ZeroTier, and Twingate are easy to set up for private networks.

Streaming & Media

  • Multi-platform servers: Jellyfin and Kodi are free media centers that work on PC, Android, iOS, and TV.
  • CloudStream: Install the app, then add extensions from the community to get content sources.
  • Stremio: Install, then use the built-in add-ons or community add-ons. Pair with Real-Debrid for smoother streaming if allowed in your region.
  • Music / audiobooks: VLC, Jellyfin, or BookPlayer on iOS handle most formats.
